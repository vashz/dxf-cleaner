# DXF Converter

Windows tool that cleans "polluted" DXF exports (e.g. Adobe Illustrator) so cutting
software gets continuous straight lines and **true arcs** instead of splines that it
breaks into point-to-point moves.

## Workflow

1. **Open DXF…** (or drag & drop a file onto the window)
2. **Clean Up**
3. Compare **Before** (left) and **After** (right). Pan/zoom is shared between both views.
4. **Export DXF…** (saves `<name>_clean.dxf` next to the original by default). If the result
   still has open paths, it first warns that nesting software will reject them unless they
   are marking lines, and asks whether to export anyway. `dxf-clean` prints the same warning
   to stderr and still writes the file.

## What Clean Up does

| Input | Result |
|---|---|
| SPLINE (Bezier/NURBS, incl. rational) | straight segments → LINE, curved → true ARCs (biarc fitting, tangent-continuous) |
| Densely tessellated LWPOLYLINE / POLYLINE | collinear points merged into lines, point runs on a circle fitted as arcs |
| Illustrator circles (4 Bezier quarters) / tessellated circles | one CIRCLE |
| LINE / ARC / CIRCLE / ELLIPSE / bulged polylines | kept; collinear lines and co-circular arcs merged |
| Pieces whose ends touch (within *Join gap*) | joined into one continuous (closed) path: the ends meet halfway, or, if that would move the shape more than the *Tolerance*, a short straight bridge fills the gap |
| Duplicate geometry | removed |
| HATCH fills, TEXT, dimensions, points… | ignored (listed under "Ignored") |
| Blocks (INSERT) | exploded with their transform |

Every result is checked against samples of the original geometry: no point moves more than
the **Tolerance** (default 0.05 drawing units, usually mm). The achieved max deviation is shown.

Output is an R12 (AC1009) DXF, the format nearly every CAM/cutting package reads, with either
continuous `POLYLINE`s carrying arc bulges (recommended) or separate `LINE`/`ARC` entities.
Full circles are always written as `CIRCLE`.

## Build

```powershell
cargo build --release
```

Produces `target\release\dxf-converter.exe` (GUI) and `target\release\dxf-clean.exe` (command line):

```powershell
dxf-clean input.dxf [-o output.dxf] [--tol 0.05] [--join 0.05] [--no-join] [--lines-arcs] [--origin] [--keep-duplicates] [--layer0]
```

Without `-o` it writes `<name>_clean.dxf` beside the input. The switches match the window's settings: `--no-join` turns off "Join touching paths", `--lines-arcs` exports separate LINE / ARC entities, `--origin` moves the drawing to 0,0, `--keep-duplicates` turns off "Remove duplicate geometry", and `--layer0` puts everything on layer 0. `dxf-clean --help` prints the same list.

## Packaging for staff

```powershell
powershell -ExecutionPolicy Bypass -File .\package.ps1
```

Runs the tests, builds everything and writes to `dist\`:

- `nhl-dxf-converter-setup-<version>.exe`: one-file installer. Installs for the current
  Windows user only (no admin rights) to `%LOCALAPPDATA%\Programs\DXF Converter`, adds
  Desktop and Start-menu shortcuts and an "Apps & features" entry for uninstalling.
  Running a newer setup updates in place; an older setup asks before downgrading (and
  refuses in quiet mode). Setup and uninstall refuse to run while the app is open.
  `/quiet` installs silently; `uninstall.exe /uninstall [/quiet]` (in the install folder)
  removes it.
- `nhl-dxf-converter-<version>-portable.zip`: unzip and run, nothing installed.

The executables are not code-signed, so Windows SmartScreen may show "Windows protected
your PC" the first time: click **More info → Run anyway**.

The icon is generated by `assets/build_icon.py` (needs Inkscape) into `assets/icon.ico`
(embedded in the exes) and `assets/icon-256.png` (window icon).
Bump `version` in the root `Cargo.toml` before packaging a new release; the setup exe and
the "Apps & features" entry take their version from it.

## Tests

```powershell
cargo test
```

`tests/fixtures/illustrator_polluted.dxf` is a real Illustrator export (2 splines + 2 hatches);
the test checks it becomes two closed 8-segment outlines like `tests/fixtures/manual_fix.dxf`.
